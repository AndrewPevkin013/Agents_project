# Обработка персональных данных (GDPR)
departments: InfoSec, HR, IT/backend, Finance

- Персональные данные сотрудников хранятся только в HR-портале и `pg-prod-01`, таблицы с префиксом `pii_`
- Шифрование: AES-256 на диске, TLS 1.3 в транзите
- Финансы хранят банковские реквизиты сотрудников 5 лет после увольнения
- Запрос субъекта данных обрабатывается за 30 дней, ответственный — CISO
- Нарушение — инцидент P1 по регламенту ИБ
