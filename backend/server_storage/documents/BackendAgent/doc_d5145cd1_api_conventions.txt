# Backend: соглашения по REST API
department: IT/backend

- Все эндпоинты версионируются: `/api/v2/...`
- Аутентификация: Bearer JWT, срок жизни 15 минут, refresh-токен 7 дней
- Пагинация: `?page=1&size=50`, максимум 200 элементов
- Ошибки возвращаются в формате RFC 7807 (`application/problem+json`)
- Имя сервиса-шлюза: `gateway-core`, порт 8080
- Таймаут на вызов downstream-сервисов: 3 секунды, 2 ретрая
